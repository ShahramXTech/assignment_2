# Tesla University Kamra – Lost & Found App

A Flutter mobile app that helps students browse lost and found items on campus.

## Features
- Lists 12 campus items using `ListView.builder`
- Each item shows its **name**, **location** and **status** (Lost / Found / Claimed)
- **View Details** button opens an item details screen using `Navigator.push`
- Search bar and status filter chips (All, Lost, Found, Claimed)
- Custom Tesla University logo drawn in code with `CustomPainter`
- Modern UI with gradient header, cards and Hero animation

## Items Included
Phone, laptop, AirPods, smartwatch, power bank, student ID, USB drive, keyboard, and cyber gadgets such as Flipper Zero, Raspberry Pi, ESP32/Arduino kit and a VR headset.
